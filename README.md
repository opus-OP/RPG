# RPG Telegram Bot

Асинхронный RPG-бот для Telegram с пошаговыми боями, рейдами, лутом,
рынком и нейросетевым нарративом (OpenAI-совместимый API).

## Возможности

### Персонажи
- **4 класса**: Воин (STR), Плут (AGI), Маг (INT), Лидер (INT + призыв стража)
- **Система характеристик**: STR, AGI, INT — все боевые статы рассчитываются из них
  - HP = 50 + STR × 12
  - ATK = 4 + STR + INT × 0.5 (min), 8 + STR × 1.5 + INT (max)
  - DEF = STR ÷ 3 + бонусы экипировки
  - Уклонение = min(AGI × 0.02 + бонусы, 50 %)
  - Крит = min(AGI × 0.02 + бонусы, 50 %)
  - Крит-множитель = 2.0 + INT × 0.05 + бонусы
- **Распределение очков**: +3 очка характеристик за уровень через UI-кнопки
- **До 3 персонажей** на аккаунт, макс. уровень 50
- Экипировка: оружие, броня, аксессуар — с износом и ограничениями по уровню/классу

### Рейды
- **5 локаций** (ур. 1–15): Пещера гоблинов, Тёмный лес, Горный перевал, Забытые катакомбы, Цитадель дракона
- **1–4 врага за рейд**, случайный выбор из пула локации
- **Пошаговый бой с инициативой**: бросок 1d20 + AGI ÷ 5, сортировка по убыванию
- **Онлайн-мультиплеер** (до 4 игроков): создание лобби, код для приглашения, FCFS-бой
- **Ивенты (30%)** между энкаунтерами: проверки STR/AGI/INT, награды (золото, предметы, баффы, хил, урон)
- **Компаньон** (класс Лидер): призыв стража, его статы зависят от характеристик лидера, ходит сразу после владельца
- **Смерть**: соло — рейд провален; мультиплеер — рес с потерей прочности экипировки
- **Кулдаун** каждые 3 рейда
- **Дроп** оружия с мобов (шанс, редкость, уровень локации)

### Боевая система
- Криты, уклонение, броня, случайная составляющая урона
- **Статус-эффекты**: отравление, кровотечение (периодический урон), оглушение (пропуск хода), щит (поглощение урона), буст крита, буст уклонения
- **Типы атак мобов**: physical, fire, ice, poison, bleed — каждый накладывает свой эффект
- **AI выбирает атрибут** для атаки игрока (STR/AGI/INT) — урон = base_dmg + выбранный стат

### Нейросетевой нарратив
- **4 последовательных запроса**: модификаторы → описание атаки игрока → модификаторы врага → описание атаки врага
- **Белый список модификаторов**: WEAK_SPOT_FOUND (0.3–2.0), DODGE_BONUS, STUN, CRIT_BOOST, TAUNT
- Каждый модификатор имеет target (player/enemy) и range
- OpenAI-совместимый API, настраиваемая модель, таймаут, ретраи

### Предметы и экономика
- **Генератор оружия**: 32 паттерна из JSON, редкость (обычный → легендарный), множители эффектов (×1.0–4.5)
- **Атрибуты оружия**: одноручное/двуручное/парное/дальнее, стихии (огонь/лёд/молния/яд/свет), scaling STR/AGI/INT
- **Рынок**: P2P-торговля, комиссия 5% (сжигается), пагинация
- **Прочность** предметов: износ от боя и смерти, поломка при 0

### Нейросетевой API
- URL, ключ и модель настраиваются через переменные окружения
- Повторы при ошибках (2 попытки), таймаут 15 с
- Валидация JSON-ответа: белый список модификаторов, проверка диапазонов

### Команды бота

| Команда | Описание |
|---------|----------|
| `/start` `/menu` | Главное меню |
| `/create` | Создание персонажа (выбор класса, имени) |
| `/profile` | Статистика, экипировка, распределение очков |
| `/inventory` | Инвентарь (надеть/снять/продать/выбросить) |
| `/location` | Выбор локации → начало рейда |
| `/market` | Рынок (просмотр/покупка) |
| `/characters` | Переключение / удаление персонажей |
| `/raid` | Вернуться в активный рейд |
| `/raidjoin` `<код>` | Присоединиться к онлайн-рейду по коду |
| `/help` | Список команд |
| `/toprpg` | Топ-10 игроков по уровню и по золоту |

**Админ-команды** (после `/admin пароль`):
| `/debug` | Меню отладки |
| `/set_level N [@user]` | Установить уровень |
| `/add_gold N [@user]` | Добавить золото |
| `/add_exp N [@user]` | Добавить опыт |
| `/reset_cooldown` | Сбросить таймер рейда |

### Фильтрация чатов
Бот отвечает только в личных сообщениях и, опционально, в одном групповом чате
(задаётся через `ALLOWED_CHAT_ID`).

## Установка и запуск

```bash
pip install -r requirements.txt

export BOT_TOKEN="токен_от_BotFather"
export NN_API_KEY="ключ_нейросети"

python main.py
```

### Переменные окружения

| Переменная | По умолчанию | Описание |
|-----------|-------------|----------|
| `BOT_TOKEN` | — | Токен Telegram-бота (обязательно) |
| `NN_API_KEY` | — | API-ключ нейросети (обязательно) |
| `NN_API_URL` | `https://routerai.ru/api/v1` | URL эндпоинта |
| `NN_MODEL` | `google/gemini-3.1-flash-lite` | Модель |

### Ключевые решения

- **Все combat-статы от STR/AGI/INT**: нет отдельной per-level прокачки ATK/крит/dodge.
  Классовая идентичность — через начальное распределение атрибутов.
- **Предметы дают первичные статы** вместо прямого atk_bonus: STR/AGI/INT → формулы атаки.
  Оружие из JSON (damage_min/max) конвертируется в stat_bonus по scaling-атрибутам.
- **AI выбирает атрибут атаки**: урон = rand(atk_min, atk_max) + выбранный стат.
  Поощряет AI использовать сильную сторону персонажа.
- **NN-нарратив в 4 запроса**: модификаторы → нарратив игрока → модификаторы врага → нарратив врага.
  Модификаторы проходят белый список с диапазонами — NN не может выйти за рамки.
- **Компаньон после владельца**: та же инициатива, вставка сразу после в initiative_order.
- **Смерть в мультиплеере** не завершает рейд: рес с полным HP, потеря прочности.
- **Фильтрация чатов**: ALLOWED_CHAT_FILTER на всех CommandHandler и MessageHandler.
