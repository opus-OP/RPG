# RPG Telegram Bot

Асинхронный RPG-бот для Telegram с пошаговыми боями, рейдами, лутом, рынком и нейросетевым нарративом.

## Возможности

- **4 класса**: Воин, Плут, Маг, Лидер (призывает стража)
- **Генерация оружия**: 32 паттерна, редкость от обычного до легендарного
- **Рейды**: 5 локаций (ур. 1–15), 1–4 врага за рейд, кулдаун 7ч
- **Бой**: пошаговый, криты, уклонение, броня, временные эффекты (отравление, кровотечение, оглушение)
- **Нейросетевой нарратив**: OpenAI-совместимый API, модель описывает бой и применяет модификаторы
- **Рынок**: P2P-торговля предметами с комиссией 5%
- **Навыки и экипировка**: оружие, броня, аксессуары с разными бонусами

## Запуск

```bash
pip install -r requirements.txt

export BOT_TOKEN="<токен BotFather>"
export NN_API_KEY="<ключ нейросети>"

python main.py
```

## Переменные окружения

| Переменная | По умолчанию | Описание |
|-----------|-------------|----------|
| `BOT_TOKEN` | — | Токен Telegram-бота (обязательно) |
| `NN_API_KEY` | — | API-ключ нейросети (обязательно) |
| `NN_API_URL` | `https://routerai.ru/api/v1` | URL эндпоинта |
| `NN_MODEL` | `google/gemini-3.1-flash-lite` | Модель |

## Команды бота

- `/start` — главное меню
- `/create` — создать персонажа
- `/profile` — статистика и экипировка
- `/inventory` — инвентарь (надеть/снять/продать)
- `/location` — список локаций → рейд
- `/market` — рынок
- `/characters` — переключение персонажей

## Структура

```
ai/           — нейросетевой нарратив
bot/          — Telegram-хендлеры и клавиатуры
core/         — боевая система, персонажи, классы, предметы, экономика, рейды
data/         — SQLite-хранилище, JSON-шаблоны (мобы, локации, оружие)
utils/        — RNG, валидаторы
config.py     — все константы
main.py       — точка входа
```
