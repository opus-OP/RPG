# Исправления

## Критические
- **Нельзя было добить врага.** Победа над врагом не фиксировалась (код после `return` не выполнялся),
  поэтому бой не завершался, пока врага не убивал страж. Теперь убийство игроком, стражем или ядом/кровотечением завершает бой.
- **Результат хода игрока не показывался** (урон, нарратив нигде не отправлялись).
- **Смерть была навсегда.** `alive=False` никто не сбрасывал, персонаж не мог ходить в рейды.
  Теперь в конце любого рейда (победа, поражение, побег) персонаж воскресает с полным HP.
- **Онлайн-рейд работал только у создателя.** Остальные участники не получали `raid_id`, рейд для них «не существовал».
  Сессия теперь общая (из БД), уведомления идут в чат рейда или в ЛС каждому участнику.
- **В рейде пропускались враги:** номер боя увеличивался и при победе, и при нажатии «Следующий».
- **Статус-эффекты хранились по роли хода («attacker/defender»), а не по участнику.** Яд моба на игроке тикал по самому мобу;
  `TAUNT` игрока давал щит врагу; `STUN` оглушал самого игрока; эффекты тикали на каждом ходу обеих сторон
  и баффы на себя исчезали до срабатывания. `WEAK_SPOT_FOUND` у врага игнорировался.
- **Шаблон класса менялся при распределении очков** (общий объект `StatBlock`): каждый «+1 к силе» делал сильнее всех новых персонажей класса.

## Серьёзные
- Одинаковые `uid` у предметов (`loot_0`, `wpn_0`): надеть/продать можно было не тот предмет. Теперь uid уникальны;
  у старых сохранений дубликаты исправляются при загрузке.
- Отмена объявления на рынке уничтожала предмет; после продажи объявление можно было «отменить» ещё раз. Теперь предмет возвращается, отмена только у активных. Добавлена кнопка «Снять с продажи».
- Продажа сохраняла устаревшую копию персонажа (терялись золото и прогресс).
- Повторное имя при создании перезаписывало существующего персонажа; не проверялись символы и длина (кнопки с длинными именами ломались).
- Бонус `hp_bonus` предметов не влиял на максимальное HP.
- Любое получение опыта полностью лечило персонажа.
- Кулдаун работал наоборот (после каждой победы, пока не умрёшь 3 раза).
- Нейросеть с нечисловым `value` ронял бой (`TypeError`); мусорные значения теперь игнорируются.
- Ход игрока не имел таймаута: AFK-игрок блокировал рейд. Добавлен.
- Пароль админа был зашит в код (`krop`); теперь `ADMIN_PASSWORD` из окружения.
- Побег из группового рейда завершал его для всех; теперь выходит только покинувший.
- Бесконечный «стан-лок» от ледяных мобов: после оглушения 2 хода иммунитета.
- Лидеры в групповом рейде не получали стража; баффы защиты от событий не действовали при атаке врага.
- Markdown в имени/описании ломал профиль (`BadRequest`), теперь есть откат на обычный текст.
- Прочее: `/raidjoin` не проверял допустимый чат, `enemy_max_hp` мог быть меньше текущего HP, перезапуск бота мог переиспользовать id проданных объявлений.

## Что осталось на ваше усмотрение
- `RAID_COOLDOWN_HOURS = 0.1` (6 минут) похоже на отладочное значение.
- Классовые ограничения оружия (`allowed_classes`) учитываются только при выпадении, а не при надевании.
- Большинство сообщений используют `**жирный**` без `parse_mode`, поэтому звёздочки видны как текст.
- Состояние персонажа «читается, меняется, пишется» без блокировок: параллельные действия одного игрока теоретически могут затереть друг друга.
